# 🎵 Spotify Clone – Web Player

A responsive **Spotify-inspired music streaming web interface** built using **HTML and CSS**. This project recreates the visual layout of Spotify's web player, including the sidebar navigation, music cards, navigation bar, and bottom music player interface.

## 📌 Project Overview

This project is a frontend development project created to practice and demonstrate skills in **HTML and CSS**. The design is inspired by the Spotify Web Player and focuses on creating a clean, dark-themed music streaming interface.

The project includes different sections such as:

* Home and Search navigation
* Your Library section
* Playlist and podcast cards
* Recently Played section
* Trending music section
* Featured Charts
* Music player controls
* Playback progress bar
* Responsive layout for different screen sizes

## 🛠️ Technologies Used

* **HTML5** – Used to structure the webpage
* **CSS3** – Used for styling, layout, responsiveness, and animations/interactions
* **Font Awesome** – Used for icons
* **Google Fonts** – Used for the Montserrat font
* **Git & GitHub** – Used for version control and project hosting

## ✨ Features

* 🎧 Spotify-inspired dark user interface
* 📚 Sidebar with Home, Search, and Library sections
* 🎵 Music cards for different playlists and charts
* 📱 Responsive layout using CSS media queries
* 🎛️ Bottom music player interface
* ⏯️ Playback control icons
* 📊 Music progress bar
* 🔍 Clean and organized frontend structure
* 🖼️ Custom image assets and icons

## 🖥️ Sections of the Website

### 🏠 Home & Search

The sidebar provides navigation options for Home and Search.

### 📚 Your Library

The library section contains options for creating playlists and discovering podcasts.

### 🎶 Music Cards

The main content area displays playlist and chart cards under sections such as:

* Recently Played
* Trending Now Near You
* Featured Charts

### 🎧 Music Player

A fixed bottom music player provides the visual interface for:

* Previous track
* Play/Pause
* Next track
* Shuffle/Repeat controls
* Playback progress

## 📱 Responsive Design

The website uses CSS media queries to adapt the interface to smaller screen sizes. Navigation elements are selectively hidden on smaller screens to maintain a clean layout.
